Imagens devem ter texto alternativo

WCAG 1.1.1 2×

Por que importa: Leitores de tela não enxergam a imagem: sem texto alternativo, a pessoa cega ouve só "imagem" ou o nome do arquivo.

Como corrigir: Adicione alt="..." descrevendo o que a imagem comunica. Se for só decoração, use alt="" (vazio).

Foco do teclado invisível

WCAG 2.4.7 6×

Por que importa: Quem navega pelo teclado (Tab) precisa ver onde está. Sem contorno de foco, a pessoa fica "às cegas".

Como corrigir: Não remova o outline. Se quiser mudar o visual, use :focus-visible { outline: 3px solid #111; outline-offset: 2px; }.

Áreas de toque devem ter pelo menos 24×24 px ou espaço suficiente ao redor

WCAG 2.5.8 4×

Por que importa: Botões e links muito pequenos ou colados uns nos outros são difíceis de acertar para quem tem tremor, mobilidade reduzida ou usa o celular.

grave

Ordem de foco salta para trás

WCAG 2.4.3 2×

Por que importa: O Tab deveria seguir a ordem de leitura (de cima para baixo, da esquerda para a direita). Saltos fazem a pessoa perder o contexto.

Como corrigir: Deixe a ordem do HTML igual à ordem visual. Evite reordenar com CSS (order, flex-direction: reverse, position) e evite tabindex positivo.

  • 5. <a> "Primeiro no código" → 6. <a> "Segundo no código" (sobe 18px)

Os elementos devem ter contraste de cor suficiente

WCAG 1.4.3 1×

Por que importa: Pessoas com baixa visão, daltonismo ou usando o celular no sol não conseguem ler texto com pouco contraste.

Como corrigir: Escureça o texto ou clareie o fundo até chegar a 4,5:1 (texto normal) ou 3:1 (texto grande, a partir de 24px ou 19px em negrito).
